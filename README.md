# Desk

> [!WARNING]
> ## **NOT READY FOR PRODUCTION**
>
> Con Services is under active development. Expect breaking changes, missing
> features and bugs. Do not use it for real events or real data yet.

Shared support inbox module for Con Services: reads support mailboxes over IMAP, turns
mail into conversations and sends replies over SMTP.

Documentation: [Desk on the Con Services site](https://aglelectronics.github.io/con-services/modules/desk/).
Changes: [CHANGELOG.md](CHANGELOG.md).
